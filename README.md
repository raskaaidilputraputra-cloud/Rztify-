# RzTify

Unggah semua isi folder ini ke akar repo GitHub, lalu aktifkan GitHub Pages
(Settings > Pages > Deploy from a branch > main > / (root)).

Alamat akan menjadi https://NAMAKAMU.github.io/NAMA-REPO/

Setelah itu, di Firebase Console > Authentication > Settings > Authorized domains,
tambahkan NAMAKAMU.github.io agar login Google berfungsi.
